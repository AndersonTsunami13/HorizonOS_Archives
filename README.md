# 🏛️ HorizonOS Archives

> "Sem isso aqui, vocês nem saberiam da existência
> do nome HorizonOS."

## 📜 Sobre

Este repositório preserva os arquivos históricos
dos primeiros projetos que deram origem ao HorizonOS.

Antes do Oneplex, antes das versões mais recentes
e antes de toda a evolução do projeto, existia isto.

Estes arquivos representam o início de uma jornada
de aprendizado, experimentação e desenvolvimento.

## ⚠️ Aviso

Este é um arquivo histórico.

O código pode conter funcionalidades incompletas,
bugs, dependências antigas e práticas que já não
são utilizadas nas versões atuais.

Os arquivos são preservados principalmente
por seu valor histórico.

## 🕰️ Propósito

Preservar as origens do HorizonOS e documentar
a evolução do projeto ao longo do tempo.

**Toda grande história tem um começo.**
